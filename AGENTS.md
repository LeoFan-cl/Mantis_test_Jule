This is a Swift library for iOS that provides an image cropping UI.

## Project Structure

*   `Sources/Mantis`: The main source code for the Mantis library.
*   `Tests/MantisTests`: Unit tests for the Mantis library.
*   `Example`: An example Xcode project demonstrating how to use Mantis with UIKit.
*   `SwiftUIExample`: An example Xcode project demonstrating how to use Mantis with SwiftUI.
*   `Package.swift`: The Swift Package Manager manifest file.
*   `Mantis.xcodeproj`: The Xcode project for the Mantis framework.

## Building and Testing

This project uses Swift Package Manager.

### To build the project:

```bash
swift build
```

### To run the tests:

```bash
swift test
```

You can also open `Mantis.xcworkspace` in Xcode and build or test from there.
